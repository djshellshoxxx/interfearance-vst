# Privacy

Interference works entirely offline.

- It makes no network connections: no telemetry, analytics, update checks, licence server or crash upload.
- It stores only: your presets (`Documents\Interference\Presets`), your options (`%APPDATA%\Interference`),
  and — only when you switch them on in Help > Debug — a crash log and a troubleshooting file on your own disk.
- The troubleshooting file and crash log contain the plug-in's settings, version, sample rate / block size, host
  name, OS version, CPU model, memory size, the preset / options folder paths (which include your user name) and
  recent plug-in events. They contain no audio and no personal files. Open them in a text editor to see exactly
  what they hold before sending. They are sent to
  support only if you choose to attach them to an email yourself.
- Presets and saved projects never contain audio, file paths, device names or machine identifiers.
