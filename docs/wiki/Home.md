# Interference Wiki

Interference (repository `interfearance-vst`) is a JUCE 8 audio effect and playable sound source built from
faulty analog signal paths: a Loose Jack, an Exposed Plug Touch, Cable Handling and a Dirty Pot. Version 1.0.0,
VST3 and standalone, Windows x64, zero latency.
