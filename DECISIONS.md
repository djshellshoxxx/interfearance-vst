# Decisions (autonomous run)

- Source layout keeps `Source/Engine/Preset` instead of the spec's `Source/Presets`: moving it churns every include for no functional gain; the module boundary is the same.
- Factory bank is committed under `Presets/Factory/` (generated by `wubforge-cli bank`), no longer git-ignored: spec deliverable 4 asks for the bank as `.wfpreset` files; FactoryPresets.cpp remains the source of truth and the plugin still installs it on first run.
- AU is added only when `APPLE` (JUCE cannot build AU on Windows); main type MusicDevice because Wubforge is an instrument.
- Reverb "pre-fader" means the reverb return skips master gain (the only fader after the sends); post-fader stays the default and keeps 1.0 behaviour.
- Column 4's middle area is a tab set (Pattern / Random space / FX rack) instead of stacking the pattern editor and randomization space: the column is too short to stack them usefully at 1180x680, and the full FX parameter set needs its own scrolling page.
- The Advanced pattern editor reuses ModulationCanvas in a roll-only mode rather than a second piano-roll implementation, so both rolls share every note gesture.
- Custom scale is passed around as `Scale::customCode(mask)` inside the existing scale int, so every call site that takes a scale handles custom scales unchanged; the root degree is always forced in (a bassline needs its root for the 40% downbeat rule).
- `patBars` stays an int parameter (1-16) shown as a knob, as in Easy Mode.
- Insert mini-presets use their own `.wfinsert` JSON (name, type, p1, p2, mix) rather than `.wfpreset`: a full preset carries every parameter, a slot preset must not. Built-ins live in code (InsertPresets.h) and are also written to `Presets/Factory/Effects/<effect>/`; the menu merges built-ins with factory and user folder files by name. No in-plugin "save slot preset" dialog - users drop files in `User/Effects/<effect>/` (documented in Help).
- Slot reorder is a state swap; the engine's existing 10 ms per-slot type crossfade covers the transition.
- Drag-out renders 48 kHz / 24-bit WAV for the pattern length into `<AppData>/DragOut/` (cleared per drag); Alt-drag drops the pattern MIDI (Pattern Mode only). Rendering is synchronous on the message thread, like the Export dialog.
- Canvas lanes map y (0..1) absolutely over each parameter's range: cutoff 30 Hz-18 kHz exponential, resonance 0-1, depth/rate replace the Movement/Speed macros (rate snaps to the same divisions the canvas labels), drive -12..+36 dB, sub level -18..+6 dB (never off, Sub Presence Rule), pitch +/-12 semitones. Evaluated once per block (the destinations are smoothed).
- Lanes drive only while the transport plays or an offline render free-runs (fxchain.md 14); the validator therefore judges what actually plays.
- Parameters with no matrix destination show "Assign to macro" / "Automate with" disabled rather than creating a routing somewhere else; an existing identical routing is reused instead of duplicated.
- "Map to note pitch / velocity" are implemented as matrix routings from the Note Pitch / Velocity sources, the same mechanism as everything else.
- XY pad "dropdowns" are popup menus on the pad's two axis labels; the recorded stroke is resampled by arc length into 16 handles per lane.
- Handle "Lock position" and lane colour are stored in the engine state and presets (small optional JSON fields, absent when default, so older presets load unchanged).
- Dropping a history thumbnail on the export handle recalls that entry and opens the normal export dialog (the renderer renders the live sound).
